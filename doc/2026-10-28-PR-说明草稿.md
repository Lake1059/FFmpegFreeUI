# 中文 PR 说明：UI 与 HDR VMAF

本次在原 PR 上追加提交，不另开 PR，也不重写已有历史。按用户要求，Agent 相关源码保持 PR 基线；后续改进仅涉及 UI/VMAF 与验证支持。本轮同时提交此前已确认、仅本地编译的紧凑布局与观看距离配色改动。

## 标题

修复浅色主题与 HDR VMAF 目录，完善提示边界和模型分组配色

## PR 正文

### 当前范围

本 PR 仅保留 UI、HDR VMAF 及其构建/验证支持，不再包含系统提示词文件化、技能资料、专用工具、硬件信息扩展或 AVIF 临时批次并行。软件原有 Agent 功能保持基线实现，不是删除原有功能。

### 主题与局部界面

- 浅色模式普通标题栏按钮悬停保持深色图标、背景变深；深色保留原反馈，关闭按钮保持红底白图标。
- 公共主题层统一文本、下拉、列表、详情行、导航、动态编辑框和 LakeUI 输入弹窗选中背景：浅色 `#D6DEE6`，深色 `#565656`。
- 输入弹窗仅统一选中色，不重复转换已配色的背景/文字；毛玻璃不再削弱选中背景。
- 许可证页面在浅色下使用浅紫购买按钮与深色文字，悬停/按下同步；深色恢复原配色。
- VMAF 说明顺序为 V1/V0、4K、距离、HFR、HDR、CUDA。模型下拉最多 **12 行**，其余通过滚动查看。

### 模型分组、配色与紧凑布局

- 四项旧 V0/NEG（普通、CUDA、4K、4K CUDA）的悬停说明统一为“旧模型，不推荐”。
- 旧 V0 区之后追加五行：普通文字、左对齐、无胶囊的“下列模型是非neg模型，强烈不推荐”，随后为普通、CUDA、4K、4K CUDA 四项非 NEG 模型。
- 非 NEG 使用 `vmaf_v0.6.1`、`vmaf_4k_v0.6.1` 的对应组合，把距离/HFR/HDR 三列合并为“非neg模型”大胶囊，不移动 CUDA 列。
- 警示行不是模型，点击保留原选择，按键/滚轮跨行；本地项插入和刷新后仍保持映射与分组正确。非 NEG 不进入 AUTO，缺少模型或 CUDA 滤镜时手动评测前明确拦截。
- SubSample 宽度 **150→132**，为模型框让出 **18 逻辑像素**，标题同步对齐，Pooling 不变；保留非 NEG 大胶囊的 **160** 原宽，解决最后一项收起时 CUDA 隐藏，不采用缩窄非 NEG 的方案。
- 胶囊高度 **24→22**，下拉行高 **36→32**，上下留白每侧 **6→5**，仍显示十二行。
- 按参数类别区分颜色，观看距离 **1.5H→3H→5H** 使用由略深到浅的紫色；1.5H 已再次稍调浅，仍深于 3H。浅/深色分别适配，正常状态文字与胶囊底色对比度至少 **4.5:1**；标签文字完整保留。

### HDR VMAF 目录、提示与 AUTO

- 胶囊常规固定列为版本 / 4K / 距离 / HFR / HDR / CUDA，CUDA 位于 HDR 之后。
- 官方八项 HDR 普通/HFR 模型在初始化和刷新时始终显示；保留扫描到的新模型并去重。目录显示与运行库名称检测分离，AUTO 不使用未检测项，本地 JSON 入口保留。
- HDR 简介在原分类说明后补上“支持 HDR”，例如“标准 3H 观看距离，默认场景，支持 HDR”；HFR/H 术语段落保留，不显示模型名、运行库状态或引擎要求。
- 所有模型提示略缩为 **320 逻辑像素**（150% 下 **480 像素**），仍保持同宽，高度随文字换行变化。
- 修复窗口未铺满显示器时介绍框越过窗口边缘：优先约束在**主窗口客户区与显示器工作区的交集**内，右侧不足时翻到左侧，并约束上下边界；窗口小到无法容纳提示时退回显示器工作区。
- 根据原视频 PQ/HLG 优先同档已检测 HDR，缺失时回退 SDR 并警告；沿用既有分辨率、距离、版本、HFR 和 NEG 回退规则。
- 刷新后不继承已消失内置模型/CUDA 项的旧检测状态，保留手选本地模型。HDR 使用真实颜色标记，缺少必需信息时不猜测、不暗中进行 HDR→SDR 转换。

**边界：本 PR 不包含 FFmpeg 引擎补丁。真实 HDR 评分未验收，模型可见或名称检出不代表当前引擎已经完成支持；“支持 HDR”是模型类别说明，不是本机评分已通过的承诺。**

### 撤除项

- 现有 Agent 目录、启动入口与编码队列保持 PR 基线。
- 撤除本 PR 新增的默认资料目录、文件安装/读取机制和项目嵌入项，以及技能、专用工具、AVIF 批次扩展和配套测试。
- 历史提交和本地历史证据保留，用户已有运行资料不自动删除。

### 构建与验证

- 保留 LakeUI 本地 DLL 覆盖机制；缺失时使用固定官方 NuGet `LakeUI 5.116`。其余既有依赖不改动。
- 当前定向集合 **11 项通过、0 失败**，包含模型分组/索引/选择保护、AUTO 排除非 NEG、模型与 CUDA 能力拦截、胶囊配色与对比度，以及相关 UI/HDR 检查。
- 独立设置运行真实质量评测窗体，浅/深色各检查 **25 个**提示，均为 480 像素且文字完整；每种主题覆盖四种窗口边缘定位，确认同时位于主窗口与显示器内，记录截图和实际坐标。
- 浅/深色各检查 370/373/405 逻辑像素三种模型框宽度，从实际截图确认最后一个模型的 CUDA 均可见；验证 SubSample/标题对齐、紧凑行距与三档紫色。不操作用户主程序。
- 许可证页复用原始实测，本轮对应源码摘要未变。旧混合范围测试不作为当前通过数；本轮未验收真实 HDR/非 NEG 评分、100% 系统缩放或多显示器跨屏。
- 不提交二进制、缓存、测试媒体、用户配置或私有端点，不启用自动合并，不发布 GitHub Release。
