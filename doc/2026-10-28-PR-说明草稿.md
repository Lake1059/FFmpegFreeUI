## PR 正文

### 变更概述

修复浅色模式下标题栏悬停、选中内容和许可证页面的可读性；补齐 HDR VMAF 官方模型目录与 AUTO；将 Agent 系统提示词及技能改为可编辑文件，增加包含真实预设和完整 CUDA 滤镜参考的编码技能。

### 主题与局部界面

- 普通标题栏按钮在浅色下保持深色悬停图标、背景变深；深色保留原反馈，关闭按钮保持红底白图标。
- 公共主题层统一文本、下拉、列表、详情行、导航、动态编辑框及 LakeUI 输入弹窗选中背景：浅色 `#D6DEE6`，深色 `#565656`；不对已配色弹窗重复转换背景。
- 许可证页面的浅色购买按钮改为浅紫色，文字保持深色；悬停/按下状态同步，许可证编号使用协调紫色。深色主题原配色不变。
- VMAF 模型说明补上 HDR，顺序为 V1/V0、4K、距离、HFR、HDR、CUDA；模型下拉最多显示 **12 行**，保留滚动和其余布局。

### HDR VMAF 模型目录与 AUTO

- 模型胶囊固定列为版本 / 4K / 距离 / HFR / HDR / CUDA，CUDA 右移一列。
- 官方八项 HDR 普通/HFR 模型始终显示，不因旧 FFmpeg 未包含模型名称而隐藏；保留运行库发现的新模型，并按名称去重。
- 区分“官方目录项”与“运行库已检测到名称”。未检测项明确提示，AUTO 不会使用；手动评测前说明所需引擎，本地 JSON 入口保留。
- AUTO 根据原视频 PQ/HLG 优先同档 HDR，缺失时回退 SDR 并警告；沿用既有分辨率、观看距离、版本、HFR 和 NEG 回退规则。
- 刷新后不沿用已消失内置模型或 CUDA 项的旧检测状态，保留手选本地模型。
- HDR 预处理保留真实颜色标记，缺少必需标记时不猜测、不暗中进行 HDR→SDR 转换。

**引擎边界：所测 FFmpeg 不能加载新 HDR 模型，正确评分还依赖完整颜色信息传递及转换支持。本 PR 完成应用侧目录和选择逻辑，不是 FFmpeg HDR 引擎补丁，不宣称真实 HDR 评分已通过。**

### 可编辑 Agent 与编码技能

- 静态提示词迁至 exe 旁的 `Agent/agents.md`，技能在 `Agent/skills/<技能>/`，内置资料嵌入程序并只补缺失文件，不覆盖用户修改或空文件。
- 每次新请求/技能读取使用磁盘当前内容；保留原操作资料库、自定义技能发现、旧工具及别名入口。
- 权限和联网事实仍动态追加，工具执行端继续校验权限；读取限制路径、设备名、链接及文本长度。
- `nvidia-video` 包含五份 NVENC 参考；RTX 40+ 默认优先 NVENC，尊重软编码目标，区分 NVDEC/NVENC，覆盖不兼容输入的 CPU 解码＋NVENC 回退。
- `avif-aom` 仅在明确要求 AVIF 时使用，单任务单线程并接通实际批次并行；不修改全局并发或放大无关视频任务，批次结束清理临时上限。
- `audio-nmr-aac` 包含 NMR AAC 参考及质量、SoXR、封面/元数据映射；独立音频与视频 Opus 默认推荐分流。
- 移除本次 VPY 方案、脚本参考和技能引用；不拆除应用既有帧服务器功能，不删除用户自有脚本或预设。

### 全 CUDA 滤镜规则与完整参考

- 用户明确要求全 CUDA 时，当前构建能在 CUDA 实现的旋转、缩放等操作**必须使用 CUDA 滤镜**，不因面板普通选项方便而切 CPU。
- 增加 `cuda-filters.md`，逐项说明所测构建全部十二项 CUDA 滤镜的功能、参数、示例及输入/输出限制：转置/旋转/镜像、缩放/格式、双边降噪、两种反交错、抠像、叠加、填边、范围转换、代表帧、上传和 CUDA VMAF。
- 补充下载、设备映射、可选 NPP 及其他 GPU API 的边界；不猜造当前构建未提供的滤镜，不把颜色范围转换冒充 HDR tone mapping。
- 明确清除同一操作产生的 CPU 重复滤镜，检查实际生成命令；缺 CUDA 能力或 NVDEC 不兼容时，先说明无法满足全 CUDA，用户同意后才改用混合方案。
- 内置资料共 **25 个文件**，包含四个技能目录、七份参考预设和新增 CUDA 参考。

- 固定官方 NuGet `LakeUI 5.116` 作为相邻 DLL 不存在时的回退，保留原覆盖机制，其他固定依赖未升级。
- **21 项定向检查通过，0 失败**：主题/弹窗/许可证颜色、HDR 提示与十二行、HDR 目录与 AUTO、刷新状态、Agent 文件/权限边界、无 VPY、CUDA 技能、七份预设命令及队列隔离。
- 三张 AVIF 真实队列并行完成，观察到三个不同 FFmpeg 进程重叠，全局并发不变、临时上限归零。
