# 中文 PR 说明：UI 与 HDR VMAF

本次在原 PR 上追加撤销提交，不另开 PR，也不重写已有提交历史。按用户最新要求，Agent 相关源码恢复到 PR 基线，本次新增资料与配套测试撤除。

## 标题

修复浅色主题与 HDR VMAF 目录，统一模型提示宽度并调整许可证配色

## PR 正文

### 当前范围

本 PR 仅保留 UI、HDR VMAF 及其构建/验证支持，不再包含系统提示词文件化、技能资料、专用工具、硬件信息扩展或 AVIF 临时批次并行。软件原有 Agent 功能保持基线实现，不是删除原有功能。

### 主题与局部界面

- 浅色模式普通标题栏按钮悬停保持深色图标、背景变深；深色保留原反馈，关闭按钮保持红底白图标。
- 公共主题层统一文本、下拉、列表、详情行、导航、动态编辑框和 LakeUI 输入弹窗选中背景：浅色 `#D6DEE6`，深色 `#565656`。
- 输入弹窗仅统一选中色，不重复转换已配色的背景/文字；毛玻璃不再削弱选中背景。
- 许可证页面在浅色下使用浅紫购买按钮与深色文字，悬停/按下同步；深色恢复原配色。
- VMAF 说明补上 HDR，顺序为 V1/V0、4K、距离、HFR、HDR、CUDA。模型下拉最多 **12 行**，其余项目通过滚动查看，不重排其余页面控件。

### HDR VMAF 目录与 AUTO

- 胶囊固定列为版本 / 4K / 距离 / HFR / HDR / CUDA，CUDA 右移一列。
- 官方八项 HDR 普通/HFR 模型在初始化和刷新时始终显示，不因旧 FFmpeg 缺少名称而消失；保留扫描到的新模型并去重。
- 区分官方目录与运行库名称检测，AUTO 不使用未检测项，手动评测前说明引擎要求；本地 JSON 入口保留。HDR 悬停提示只沿用相同分类 SDR 的简短说明与 HFR/H 术语解释，不显示模型名、运行库状态或引擎要求。所有模型提示固定为参考图对应的 **343 逻辑像素**（150% 下 **515 像素**），包括 AUTO、HDR、SDR 和短 V0/NEG/CUDA 项，不再随文本长短收窄；高度仍按换行变化。
- 根据原视频 PQ/HLG 优先同档已检测 HDR，缺失时回退 SDR 并警告；沿用既有分辨率、距离、版本、HFR 和 NEG 回退规则。
- 刷新后不继承已消失内置模型/CUDA 项的旧检测状态，保留手选本地模型。
- HDR 处理使用真实颜色标记，缺少必需信息时不猜测、不暗中做 HDR→SDR 转换。

**边界：当前所测 FFmpeg 无法加载新 HDR 模型，正确评分还依赖完整颜色信息传递与转换支持。本 PR 是应用侧列表/选择支持，不是 FFmpeg 引擎补丁，不宣称真实 HDR 评分已通过。**

### 撤除项

- 删除本 PR 新增的默认资料目录、文件安装/读取类和项目嵌入项。
- 撤回技能、专用工具及 AVIF 批次上限，不保留相关预设/滤镜技能文档。
- 测试入口移除上述专用检查，文档不再将它们列为交付内容。历史提交和本地历史证据保留，用户已有运行资料不自动删除。

### 构建与验证

- 保留 LakeUI 本地 DLL 覆盖机制；缺失时使用固定官方 NuGet `LakeUI 5.116`，保证本次 UI 构建可复现。其余既有依赖不改动。
- 当前定向集合为 **10 项**，覆盖主题往返、标题栏、输入弹窗、许可证配色、HDR 提示、十二行配置、模型分类/目录/AUTO/刷新状态、颜色标记与扫描前缀。
- 实际页面预览使用独立设置、不操作用户主程序。浅/深色各逐项检查 **19 个**模型提示的实际宽度及文字区域，并覆盖滚动后重建、左右翻转与屏幕底部定位；保留截图和 JSON 证据。许可证页复用上轮实测，本轮相关源码未变。
