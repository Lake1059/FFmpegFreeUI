## 已修复问题

- **进程超时与取消**：原先等待进程和两路输出的 `WhenAll` 可能被 EOF 阻塞，导致取消分支无法执行；stdin 写入也没有纳入超时。现在写入、刷新、退出和输出读取都受超时控制，输出持续排空但限制缓存长度；PowerShell 清理不再无限同步等待输出。
- **文件操作**：保留空参数、重复参数和参数首尾空格，去除 UTF-16 BOM 对文本的污染。目录移动拒绝相同及父子路径；覆盖目标目录时先备份，移动失败恢复目标。目录枚举先限制数量再排序，并跳过重解析点。HTTP 工具限制响应缓冲大小和完整读取时间。
- **端点协议**：HTTP 请求与 JSON 文档显式释放。流式读取覆盖响应体超时；缺少完成标志、空流和错误事件不会当成成功。工具调用因输出长度截断时不执行工具。HTTP 超时与用户取消分别处理，错误 JSON 不再伪装成成功响应。
- **会话恢复**：加载时把上次中断的运行标成取消，并为缺失的工具返回补充“结果未知”记录；保存时不改变仍在运行的任务。工具批次开始及返回后保存进度。索引拒绝跨目录文件名，非法 ID 生成无碰撞文件名，旧记录中的空集合成员被规范化。
- **上下文**：每一轮工具循环都重新检查压缩预算，避免长任务只检查首次请求。调整方向按消息 ID 去重，取消时刷新尚未展示的流式缓冲。当前版本的用户原文不再被旧版迁移逻辑删去“调整方向：”前缀。
- **模型与交互**：新建、删除和切换对话保留底部下拉框选项与当前选择；推理期间下拉框保持可操作，修改选项用于后续提交，不改动正在运行的任务设置。推理能力按端点和模型隔离，显式返回的能力优先于兜底表。只附带文件的发送不会被误判成空消息重试或停止。
- **参数与队列**：无效枚举值和非有限数字在应用参数前被拒绝；队列修改存在未匹配目标或同时指定 `all` 与具体目标时，不再悄悄执行部分任务或扩大到全部任务。

## 清理与维护约定

- 删除 `ToolRunLog`、`ToolRoundLog` 两层重复状态，直接使用 `AgentTurnActivityData`，以 `ToolCallId` 对应协议调用，以活动 ID 找回控件。
- 清理无用的页面总用量累加器、压缩计划字段、不可达的空 SSE 二次请求逻辑和空壳异步方法。
- 复用聊天请求构造、响应根对象验证及原子 JSON 写入。
- 草稿不属于 `Messages`，不能进入端点请求或上下文压缩；只有当前对话可以更新 AgentRoom。
- 完整返回保存在活动记录中，界面和复制内容只使用摘要；模型上下文保留原有工具文本长度限制。
- 多对话拥有独立的取消源、流式解析器和 PowerShell 进程；应用参数面板、编码队列及集成工具仍是共享的应用状态。
- 会话格式保持兼容。推理级别缓存版本更新为 6，旧缓存会重新生成，避免复用此前未按端点隔离的数据。
