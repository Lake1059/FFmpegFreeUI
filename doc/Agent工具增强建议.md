# Agent 呈现与工具增强记录

## 搜索、询问与媒体流选择器

- 新增 `search_local_files`、`search_local_text`，仅系统访问权限可用。支持文件名通配符、相对路径 glob、递归、目录排除、分页；文本搜索增加大小写、正则、原始行列号和前后上下文。不依赖外部 rg；默认跳过链接、隐藏目录、构建目录、二进制、不可解码和超过 8 MiB 的文本文件。时间、扫描量与返回长度均有限制，部分结果通过 `stop_reason` 和 `complete` 明确标识。
- 所有权限可用的 `ask_user` 采用 LakeUI 非模态 ExMsgBox。字符长度与选项数量没有硬上限，工具描述和资料库保留简短文案的呈现建议；必填、非空、唯一及按钮单行校验仍有效。
- 询问会结束本轮运行并保存待选择问题，不占推理计数，没有工具等待超时。切换会话、关闭页面或重启程序后仍可选择；关闭询问窗口或点击‘稍后选择’保留问题，发送区的‘选择’可重新打开。点击‘取消选择’结束询问并保持停止，用户可直接补充文字或附件后继续。
- 询问期间没有挂起的 HTTP 请求或异步工具等待，同批后续调用标记为 skipped。回答作为原工具结果保存到所属会话后才发起新一轮模型请求；后续网络错误沿用原重试流程，不重新执行已经回答的询问。
- LakeUI 增加可由调用方管理的 `CreateExMsgBox` 窗体工厂，并修复自定义按钮 Enter 路径和共享按钮字体的释放。
- 媒体流选择器双击项切换勾选状态。ffprobe 读取改为异步，30 秒超时；更换文件与窗口关闭会取消读取并终止进程，迟到结果不能更新新列表或已释放窗口。输出分别读取并限制捕获量，避免原有两个事件线程并发写一个列表。
- 选择器释放时解除拖放事件、分离窗口样式、清空列表与选择缓存、解除目标引用并释放自己创建的字体；借用的主窗口图标不主动释放。

## 本次修改

- LakeUI AgentRoom：流式增量的贴底请求随现有计时器合批；固定高度的轮次和工具标题、运行/错误状态变化只触发重绘；清空和流式完成时处理待提交请求。
- 3FUI Agent：流式概览最多每 250 ms 更新一次；思考文本追加到已有条目；移动概览时保留条目资源；以弱引用键缓存工具执行状态，状态或结果变化后重新解析。
- LakeUI UltraDetailListView：普通按键、修饰键和复制快捷键保留提示窗；方向导航、编辑、Escape 等实际列表操作关闭提示窗。
- `read_local_text_file`：所有读取分支统一执行 10000 行限制，支持 `include_line_numbers`，避免拆分整份文件的行数组。
- `write_local_text_file` / `apply_local_text_patch`：支持保留 UTF-8 BOM、UTF-16/32 大小端编码；补丁拒绝有损转换无 BOM 的旧编码文件，限制文件为 8 MiB。
- `list_directory`：支持 `offset`、`limit`、`pattern`，按需枚举；返回 `entries`、`has_more`、`next_offset`，常规页控制在约 12000 字符。单个极长路径条目仍完整返回以保证翻页能前进。目录变动时分页不提供快照一致性。
- 文本读取、写入、补丁和目录枚举移出 UI 线程，并检查取消；写入在原子替换前再次检查取消。
- `run_powershell`：增加 `max_output_chars`、`success`、`stdout_truncated`、`stderr_truncated`，输出超出捕获上限后仍排空；避免为已经超限的每行额外拼接完整字符串。
- 同步更新工具定义和内置技能资料，目录返回值由原数组改为含分页信息的对象。

## 临时探针验证

使用 STA 进程创建真实控件，通过反射调用内部状态路径；未连接模型端点。临时源码计数器、测试工程和测试数据验证后清理。

| 场景 | 结果 |
| --- | --- |
| 2000 条历史轮次 + 500 个连续文本增量 | 原路径 500 次同步布局，修复后增量循环 0 次，手动触发一次合批后 1 次；文本完整 |
| 工具状态：同一份约 100 KB 结果，重复查询 500 次 | 本机一次观测：不缓存约 17 ms，缓存约 0.43 ms；修改结果和状态后正确失效 |
| 提示窗 | Ctrl、Ctrl+A/C/Insert、普通按键保留；中文选择复制通过；Escape 关闭 |
| 文本工具 | 默认行数上限、原始行号、EOF、字符上限通过；6 种 Unicode 编码补丁字节比对通过；歧义补丁不写入 |
| 目录 | 分页覆盖 207 个匹配文件，无重复；取消通过 |
| PowerShell | 中文 stdout/stderr、限额和截断标志、变量保留、失败状态、超时后重启、取消通过 |
| Agent 控制器 | 思考占位替换、增量追加、最终正文一致、后台会话不新增可见条目、清空待提交请求通过 |

这些数据衡量内部调用路径，不代表真实模型流量下的帧率或 GPU 占用。

## 建议下一步新增的工具

以下是后续工具建议；文件搜索和文本搜索已在本次实现。

| 优先级 | 建议接口 | 主要能力与价值 |
| --- | --- | --- |
| P0 | `probe_media` | 通过当前配置的 ffprobe 读取容器、视频/音频/字幕流、色彩/HDR、章节、时长和错误；允许选择字段和流，直接给模型结构化数据，减少临时 PowerShell 脚本。 |
| 已实现 | `search_local_files` / `search_local_text` | 文件名或相对路径 glob、字面量/正则搜索、上下文行、Unicode BOM 编码识别、结果分页、取消和超时；返回路径、行号、列号、命中片段及下一页位置。 |
| P0 | `start_process` / `read_process_output` / `stop_process` | 为 ffprobe、短样本编码、分析任务返回进程会话 ID；按游标读取增量输出，支持等待和进程树终止。将长任务从单次 300 秒调用中解放，并将完整输出留在本地。 |
| P0 | `preview_encoding_plan` | 根据输入媒体和参数生成真实可执行命令、输出路径、选流/滤镜关系和预估工作量；与实际命令生成器共用逻辑，帮助用户先检查再提交。 |
| P1 | `extract_media_preview` | 按时间点提取帧或短片；生成可预览附件，并在端点支持图像输入时将缩略图作为图像内容发送。现有 `get_image_info` 只能读取尺寸和格式。 |
| P1 | `analyze_media_sample` | 有范围地运行黑场、静音、裁剪、响度或 VMAF/SSIM 分析，返回时间区间和统计；复用后台进程会话，避免默认扫描整片。 |
| P1 | `preview_queue_patch` / `commit_queue_patch` | 预览一批任务的参数与输出路径差异，以版本号绑定提交；在队列状态变化时重新检查，减少逐个任务修改和部分成功。扩展已有队列工具即可。 |
| P1 | `read_tool_artifact` | 用附件 ID/路径保存完整日志与大结果，按 offset、行范围或关键词回读；模型只接收摘要和可续读位置，替代当前统一截断 16000 字符造成的信息丢失。 |
| P2 | `update_work_plan` | 把多步骤转码/诊断计划保存为可更新的工作清单，在 Agent 页显示当前步骤和完成状态；使用结构化状态供恢复运行时读取。 |

新工具应复用现有权限级别、每轮运行生命周期、取消令牌和活动记录。图像输入需按端点能力启用；分析和编码类工具应返回实际执行命令、退出码与产物路径，方便验证结果。
