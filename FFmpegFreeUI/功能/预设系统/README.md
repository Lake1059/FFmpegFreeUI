# 预设系统

`预设数据_v6.vb` 只定义可序列化的预设模型及其嵌套数据结构。

`开发者内置预设_v6.vb` 维护内置预设清单。

`预设存储_v6.vb` 负责预设文件路径、JSON 读写、预设深复制和旧数据初始化。批量复制通过 `创建预设克隆工厂` 复用一次序列化的 UTF-8 数据，每个任务仍获得独立的预设对象。保存文件仅修改副本，通过同目录临时文件替换目标文件。

`预设滤镜排序_v6.vb` 负责内置滤镜顺序、旧字段迁移及滤镜排序同步。

面板读写按参数面板的页面顺序维护。`预设面板总览_参数文本_v6.vb` 包含保存、加载、参数总览与区段调用顺序；具体控件映射和命令行构造放在相应的 `预设区段_*.vb` 文件中：

| 预设数据区段 | 面板读写 | 命令行生成 |
| --- | --- | --- |
| 输出、解码、视频编码器 | `预设区段_输出解码编码_v6.vb` | 同文件中的输入与编码器参数方法 |
| 画面帧：尺寸、抽帧、插帧、超分等 | `预设区段_画面帧_v6.vb` | 同文件中的滤镜构造方法 |
| 画面效果、烧录字幕 | `预设区段_画面帧_v6.vb` | `预设区段_画面效果字幕_v6.vb` |
| 质量、色彩管理、音频 | `预设区段_质量色彩音频_v6.vb` | 同文件中的质量、色彩与音频参数方法 |
| 剪辑、自定义参数 | `预设区段_高级流控制_v6.vb` | `预设区段_剪辑自定义_v6.vb` |
| 流控制、元数据、章节、附件 | `预设区段_高级流控制_v6.vb` | 同文件中的附加输出方法 |

`预设面板总览_兼容性_v6.vb` 负责兼容性提示。`预设命令行滤镜图_v6.vb` 负责跨区段的滤镜图与流映射编排。

`预设命令行核心_v6.vb` 负责阶段化命令行编排和二次编码日志路径。新增字段时，先在本表找到区段文件，再检查控件读写、命令行构造和总览文本。

所有命令行与面板实现仍是 `预设管理_v6` 的 Partial 部分，外部调用的类型和方法签名保持不变。
